# 那位写歌人

## 他是谁

001 苏眠第一次经历完整人生时的那个人。写歌，没人唱。最后在一间租来的屋子里，把一叠谱子收进箱子。

**他一生没有发表过任何作品。**

## 呈现规则（铁律）

**绝不给名字、绝不给长相细节。** 只允许给三样东西：

1. **一间屋** —— 租金便宜、冬天冷、窗对着别人家的墙。
2. **一支铅笔的握感** —— 指节上有茧，握笔的位置靠下。
3. **一叠谱子被合上的声音** —— 很轻，像关一个抽屉。

他出现过的所有梦都不许出现"他是谁"的答案。

## 出场节点

| 章 | 内容 |
|---|---|
| 001 | 首次入梦。醒在夜班公交上，只记得一句旋律（即《夜航》雏形） |
| 004 / 012 | 空手醒来时，苏眠下意识想找"那个箱子"——但那是别人的记忆 |
| 037 | 以"同类"的形式反复出现（未完成的人），`unfinished-song` 属于他 |
| 055 | 苏眠替这一类人把曲子写完（《问路》） |
| 066 | 他的疲惫渗到苏眠脸上（`mirror-face`） |
| 091 | 最后一次来访：一个不肯唱完自己一生的人 |
| 096–100 | 揭示：他一生未发表，唯一被带走的是一句旋律——学生抄走的。**原因不解释** |

## 回收落点

《长夜有歌》首唱时，苏眠在台下留了一个空位，并把父亲那块旧表放在座位上。

**全书不给金手指来源的解释**（准则红线 5）。他不是谜底，他是**苏眠要做的那个选择**。
