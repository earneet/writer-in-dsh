# 行业生态

## 城市

**云澜市** —— 虚构沿海城市。旧城区沿江，录音棚多集中在"南岸"一片由仓库改的园区里。城区通勤靠一条环线地铁，深夜有夜班公交（001 的开场就在这趟车上）。

**小城线索**：苏眠的家乡是云澜下属的**平江**，一个小县城。他父亲葬在那里（007《旧屋》取材于此）。

## 公司

| 名称 | 性质 | 立场 |
|---|---|---|
| **盛音** | 老牌唱片公司，老板**陆崇明** | 旧势力。逻辑是"买断一个人最好的五年"。卷二的主要对手。 |
| **云渡文化** | 平台系资本，掌握流量入口 | 不算反派，但它的算法决定谁能被听见。卷三的压力源。 |
| **潮声** | 陆微离开盛音后自己办的独立厂牌（卷三） | 小、穷、自由。 |
| **南岸 3 号棚** | 苏眠长期蹭用的录音棚 | 全书最重要的空间。老板叫**老陈**，一个只关心设备的人。 |

## 平台与榜单

- **潮汐榜** —— 自创的行业榜单。分"热歌榜"（数据向）与"潮汐年度"（评审向）。卷一 016 之后《夜航》在热歌榜上缓慢爬升——**注意：爬升要慢，不要写成一夜登顶。**
- **晚听** —— 乐评号，主笔许晚。只有一个人运营，但圈内分量最重。
- **《午夜偏移》** —— 云澜电台深夜档，主持人迟夏。凌晨两点，没有广告。

## 奖项

- **潮汐音乐奖** —— 每年一次。林知雅提名过两次，一次没拿到。苏眠在卷二第一次被提名（不是获奖）。
- **新声奖** —— 新人向，含金量一般，卷二里被用来给江迟铺路。

## 行业规矩（写作时要遵守的"物理定律"）

1. **资源是换来的**：一次打歌位、一次节目、一个推荐位，背后都有交换。没有"贵人一句话就红"。
2. **数据会说话，但慢**：《夜航》的破圈路径必须是——深夜小范围 → 有人转发 → 榜单缓慢爬升 → 被更大的人听见。**禁止一夜爆红。**
3. **版税与署名是本书最锋利的现实线**：一首歌火了，写歌的人未必拿到钱；署名权可以卖。全书所有冲突都从这里长出来。
4. **舆论翻脸很快**：同一批人被同一首歌打动，也会在下一篇稿子里骂他。写舆论要写具体账号、具体评论，不写"网友们沸腾了"。
5. **音乐是要花时间的**：录音、混音、改谱、练声都要写具体动作和时间（几点进棚、录了几遍、第几遍过的）。

## 苏眠的技术细节（一致性锚）

- 音域：中低音为主，偏凉、偏薄；不擅长高音炫技。
- 乐器：会吉他（能弹唱）、钢琴（一般，够编曲用）。
- 习惯：写词用铅笔，在烟盒背面或便利店小票上；录唱习惯脱鞋。
- 招牌动作：唱到副歌前会停半拍——这是他所有歌的共同特征，卷三被乐评人当作"风格统一"的证据。
