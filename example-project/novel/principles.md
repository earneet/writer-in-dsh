# 创作准则

> 本书一切章节的最高约束。与准则冲突的章节必须改，不以"写得更爽"为理由破准则。

## 一、一句话定位

一个出道五年不温不火的歌手，被动的梦境让他一次次活过别人的一生；醒来只记得碎片，于是他把那些碎片做成歌，唱给一个从未听过它们的时代。

**类型**：架空都市 · 文娱 · 暗爽流
**体量**：4 卷 × 25 章 ＝ 100 章，每章 2000–3000 字
**基调**：温润主调 + 冷感点缀。全书是"暖"的——为作品、为人心、为一点点被看见而写；冷只用在行业的势利、舆论的翻脸、以及主角独处时的错位感。

## 二、世界设定（铁律）

1. **架空世界**。国名、城市、平台、颁奖礼、公司全部自创，不映射真实国家与真实艺人。**一切专有平台/奖项/榜单自创**（云澜市、盛音、云渡文化、潮汐榜、潮汐音乐奖、晚听、《午夜偏移》）。
2. **地球作品从未存在**。主角梦境中的歌、书、剧本、曲子在本书世界一概不存在。因此"搬运"不构成抄袭问题——**读者知道来源，世界不知道**。这是全书最大的信息差红利。
3. **不许出现真实歌手/真实歌曲名/真实影视作品名**。需要"名作级"作品时，自创曲名与词句（详见 outline.md 作品锚）。
4. 金手指**没有系统面板、没有提示音、没有进度条、没有 AI 对话**。梦就是梦：画面、声音、情绪、一生。这是本书与主流文娱爽文最大的区别，任何一章都不得滑向系统流。

## 三、金手指规则（不可违背）

**被动 · 碎片 · 有代价**

- **被动**：梦不由他选。他无法决定今晚梦到谁、梦到什么年代、什么职业。想触发就能触发＝破设定。
- **碎片**：醒来只留下**残片**——可能是一整首歌的旋律（罕见），可能只是一个乐句、一句词、一段和声、一个故事轮廓、一种情绪质地。**记得多少是随机的，不是设定好的奖励**。
- **体验**：梦里他"是"那个人，活完一段完整人生（作家、歌手、作曲人、医生……）。那些人生的重量会留在醒来后的身体里：手指会颤、声音会哑、会莫名其妙地流泪。
- **代价**：体验越深，醒后越难分辨"哪一段是我的"。他会短暂地想起不属于自己的往事、说出不属于自己的口吻。**代价不是惩罚，是孤独**——他唱出的每一句都带着别人一生的重量，却不能说出口。
- **不可解释**：主角不知道梦从哪来，全书不给金手指来源的解释。**永远不解释**。

**成长节奏（与卷结构挂钩，硬约束）**：
- 第一卷：完全随机，一次只捞到一点，经常空手醒来（**空手也要写，且必须写**——空手是暗爽的前提）
- 第二卷：开始能感到"趋向"——同类的人反复出现（音乐人偏多），但仍不能选
- 第三卷：能在梦的边缘"停留"一小会儿，捞到更完整的东西，代价加重
- 第四卷：他不得不面对一件事——梦正在把他变成别人。他要在"继续做梦"和"做回自己"之间选。（**这是全书情感高潮，不是力量升级高潮**）

## 四、爽点配方（暗爽流，写作时逐章自检）

本作的爽**不是打脸式外放**，是**延迟引爆的错位**。四类爽点必须交替出现，单章至少命中一类：

1. **作品击中**（核心爽点）：一首歌放出去，听的人哭了、愣了、反复听、去查作曲人是谁。**重点写听众的身体反应与日常动作**（在地铁上摘下耳机、在厨房站着听完、把歌转发给一个多年不联系的人），不写数据面板。
2. **倾慕错位**：有人被作品打动而来，靠近他，欣赏他；而他知道真正的作者不是自己。**他的反应是心虚、退让、偶尔的诚实**——这比得意更爽。
3. **行业内打脸**：被轻看、被压资源、被安排到角落，然后作品自己说话。**打脸必须由作品完成，不能由主角嘴上赢**。主角越少辩解，爽感越强。
4. **生活质感**（"甜美幻想"的落点）：写听众从作品里看见自己想过而没过上的生活、想爱而没爱成的人。这一层让爽点从"他赢了"升到"我们都被安慰了"。

**禁止**：主角主动爆料自己是天才；主角对着镜头念金句；用旁白直接宣布"他火了"；用连续三个感叹号式的情绪轰炸。

## 五、叙事纪律

- **视角**：主视角第三人称限知（贴主角），可整段切换到"旁观者视角"章节（听众、同行、记者、倾慕者）——**每卷至少 2 章纯旁观视角**，这是暗爽流的关键装置，也是"群像倾慕线"的载体。
- **语言**：干净、具体、少形容词。写感受用动作和物件，不写"他心中一暖"这类直接命名情绪。
- **克制**：每章最多允许一次抒情外放，其余靠留白。留白不是不写，是**该说的时候停住**。
- **对白**：不写解释性对白。人物说半句，剩下半句在动作里。
- **对白符号**：对话使用中文引号「」。
- **章节节奏**：每章 2000–3000 字，**章末留钩**（一个动作、一句没说完的话、一条刚弹出的消息）。不写总结式结尾。
- **禁用现代网络用语**（"破防""绝了""yyds"等一律不用；行业术语不在此限）。

## 六、红线

1. 不写系统面板、不写数值、不写"叮"。
2. 不写主角吊打所有人；主角的魅力来自**作品与沉默**。
3. 感情线不写多女争夺、不写后宫式收纳。倾慕是**各自独立的、克制的、有尊严的**，每个女性角色有自己的生活与目标，主角不是她们的奖品。
4. 不出现真实艺人/作品名称。
5. 不解释金手指来源。
6. 不写悲观结局；可以有代价，不能有绝望。

## 七、每章开写前自检

- [ ] 这一章的爽点属于四类中的哪一类？（说不出＝重写本章设计）
- [ ] 有没有破坏"被动·碎片"规则？
- [ ] 有没有出现真实作品名或系统流元素？
- [ ] 章末有没有钩？
- [ ] 主角有没有主动炫耀？（有＝删）
