# 伏笔：许晚的预言

## 设置方式（033）

许晚的乐评独章。他写苏眠：风格跨度大得不合理，**"这些歌听起来不像一个人写的。"**

**写作要求**：他的本意是批评（"缺少统一的美学"），不是揭穿。这句话必须写得像一句普通的乐评套话，读者第一遍看不出分量。

## 强化节点

- 047：江迟在采访里引用这句话，当成赞美（red_herring：读者会以为这是"风格多样"）。
- 058：林知雅在她的独章里重新读到这句话，停了一下。
- 071：卷三公开之后，这句话被全网重新引用（callback）。

## 回收（071–075）

苏眠公开说"这些歌不是我一个人写的"。许晚在 071 之后公开承认自己"当时只说对了一半"——他知道的也只是字面意思。**真相的最后一层，始终只有苏眠、林知雅知道。**
