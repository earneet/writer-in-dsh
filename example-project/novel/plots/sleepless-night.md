# 伏笔：不敢睡的夜

## 设置方式（001）

第一次完整经历梦之后，苏眠开始怕睡觉——本章只给"他做的事"，不给他失眠的自觉。

**写作要求**：不写失眠的痛苦，写**他做的事**——擦一遍吉他（第三弦有锈，多擦两遍）、把水杯挪三次位置、给周宁发一条「在吗」然后撤回。

**本章已落地的写法**：他连续两夜没睡好（正文只给一句"他昨晚没睡好。前天也没。"），凌晨两点五十回到住处不开灯，在阳台上坐着。

## 强化节点

- 005：他试过熬着——第三天的凌晨四点，他在阳台上睡着，醒来时手里攥着一支笔（reinforcement：身体先于意志投降）。
- 012：连续空手醒来，他反而睡得很沉（red_herring：读者会以为问题解决了）。
- 028：他第一次意识到自己**期待**做梦（partial_reveal：这不是失眠，是上瘾）。
- 043：他开始拖到天亮才睡，宁可少捞到碎片。

## 回收（091–100）

终章他做出选择之后的第一个夜晚——他躺下，很快睡着，**没有梦**。他醒来时天是亮的。（**回收方式：他终于可以睡了。**）
