# 伏笔：那个没等到成名的写歌人

## 设置方式（001）

苏眠第一次经历完整人生：梦里他是一个四十多岁的男人，写歌，没人唱，最后在一间租来的屋子里把一叠谱子收进箱子。醒来在凌晨的公交上，苏眠只记得一句旋律。

**写作要求**：梦里**不要给名字**，也不要给他长相的细节。只给三样东西——一间屋、一支铅笔的握感、一叠谱子被合上的声音。这是全书最重要的一处留白。

## 强化节点

- 004/012：空手醒来时，他下意识想去翻那个"箱子"——但梦里没有箱子，那是别人的记忆。
- 055：《问路》——他再次梦到同一类人（未完成的人）。
- 066：他在镜子里认出那个男人的疲惫（partial_reveal：梦中人的状态渗到他脸上）。

## 回收（096–100）

终局揭示：那位写歌人一生未发表，唯一留下的是他学生抄走的一句旋律——即《夜航》的雏形。他入梦的原因**不解释**（准则铁律），只让苏眠做出选择：不再搬运。

**回收落点**：《长夜有歌》首唱时，苏眠在台下留了一个空位。
