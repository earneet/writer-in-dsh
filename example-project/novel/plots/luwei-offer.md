# 伏笔：陆微的钱

## 设置方式（028）

陆微（盛音老板之女）在录音棚外的车里给苏眠一个数字：够他两年不接任何活。她说完就补了一句"这钱没有条件"——然后自己愣了一下，因为这句话她也不太信。

## 强化节点

- 036：苏眠没拿这笔钱，但记下了这个数字（reinforcement：他后来算过，那笔钱正好等于母亲一年的治疗费）。
- 050：陆微与父亲对峙，第一次为这笔钱付出代价（partial_reveal：钱背后是她自己的份额）。
- 063：他穷到要卖设备时，那笔钱还存在一个没动过的账户里。

## 回收（卷四）

版权围剿时他动用了这笔钱——不是买资源，是买下自己早期作品的版权。**回收方式：他第一次主动使用别人的善意。**
