# 伏笔：镜中的脸

## 设置方式（066）

《镜中》完成那晚，苏眠在录音棚洗手间抬头看镜子，认出的是梦里那张疲惫的脸——不是他。

**写作要求**：不要写"他感到恐惧"。写他**先擦了一下镜子**，然后退后半步，然后回棚里把最后一段录完。

## 强化节点

- 070：他三天"不是自己"，拒绝见人（他也拒绝见周宁）。
- 091：梦中人最后一次来访之后，镜子里的脸又变回他自己——**这次他不确定自己想不想**（callback）。

## 回收（卷四）

终章他不再照镜子。他把镜子用一块布盖了——不是害怕，是"不用看了"。
