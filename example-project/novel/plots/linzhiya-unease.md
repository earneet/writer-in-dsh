# 伏笔：对不上号

## 设置方式（061）

林知雅给他做制作人，问起他上一张 EP 的曲序——他答不上来。但他随口说出了一位陌生老人的葬期（梦中记忆）。

**写作要求**：林知雅的反应要专业而具体——她没追问"你怎么了"，她只是把谱子翻过去一页。

## 强化节点

- 066：他在录音棚里用别人的口吻说话（partial_reveal）。
- 072：她开始记录——日期、他说的话、歌的完成时间。
- 075：她问出全书唯一一次直接的问题："**你还是苏眠吗？**"（她自己也不知道为什么会这么问。）

## 回收

苏眠没有正面回答。他唱了一小段只有八小节的旋律——那是他自己写的。**回收方式：回答是一段音乐，不是一句话。**
