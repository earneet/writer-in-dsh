# 伏笔：署名权条款

## 设置方式（007）

苏眠把《旧屋》投给一个小征文改编。周宁看完投稿协议，指着一条说"这个不行"——协议写的是"改编作品署名以主办方最终公布为准"。苏眠签了，因为不签就投不出去。

**写作要求**：条款原文只出现一次，之后不再复述。周宁的反应比条款本身重要——她把那张纸折了两折，装进包里。

## 强化节点

- 021–023：盛音第一次要买断，同一个条款换了个说法再次出现（reinforcement）。周宁卷壹 023 的长句就发生在这里。
- 046–050：卷二解约时，这条旧协议成了把柄（callback）。
- 076–090：卷四围剿，"代笔"污名从这条旧协议上长出来（callback）。

## 回收

卷四，苏眠最终没有用这份旧协议反击——他选择清唱。（**回收方式是不使用它**，这是本伏笔的巧处。）
